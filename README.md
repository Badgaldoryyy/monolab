## 📋 Төслийн тухай / 프로젝트 소개

**MONOLAB** - Улаанбаатар хотод байрладаг 3D хэвлэлийн захиалгат бүтээгдэхүүн үйлдвэрлэдэг компанийн албан ёсны вэбсайт.

**MONOLAB** - 울란바토르에 위치한 3D 프린팅 맞춤 제작 회사의 공식 웹사이트입니다.

## ✨ Одоогийн үндсэн функцууд / 현재 구현된 주요 기능

### ✅ Дууссан ажлууд / 완료된 작업:

1. **Нүүр хуудас** / **메인 페이지**
   - Компанийн танилцуулга / 회사 소개
   - Үйлчилгээний онцлог / 서비스 특징
   - Холбоо барих мэдээлэл / 연락처 정보

2. **Бүтээгдэхүүний хуудас** / **제품 페이지**
   - **Бүтээгдэхүүний код**: C003 - Хүүхдийн дурсгал / **제품 코드**: C003 - 아기 기념품

     - Хүүхдийн нэр / 아기 이름

     - Жин / 체중
     - Өндөр / 키
     - Төрсөн цаг / 출생 시간

## 🎨 Google Sheets Integration Guide / 구글 시트 연동 가이드

### 📝 Хэрхэн ажиллах вэ? / 작동 방식:

1. Google Sheets-д бүтээгдэхүүний мэдээлэл оруулна / 구글 시트에 제품 정보 입력
2. Google Apps Script ашиглан Web App үүсгэнэ / Google Apps Script로 웹 앱 생성
3. Вэбсайт автоматаар Google Sheets-с өгөгдөл татаж авна / 웹사이트가 자동으로 데이터 로드

| id | name | description | price | colors | image_url | active |

| 1 | Хүүхдийн дурсгал | Төрсөн өдрийн дурсгал | 40000 | Саарал,Бэйж,Цагаан | URL | TRUE |
